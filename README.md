## FAQ

### Is XCutors safe to use?

XCutors itself does not contain malicious code. However, as it loads external scripts and executors, always use trusted sources and scan with anticomponent software.

### Does it require a key or license?

XCutors is the loader. Individual executors like Synapse Z or Wave may have their own licensing. The loader assists with their activation and use.

### Which Windows versions are supported?

XCutors is designed for Windows 10 and Windows 11 64-bit systems. Older versions may not be fully compatible.

### Will this affect my Roblox account?

Using third-party executors can violate Roblox's Terms of Service and may lead to account action. Use at your own risk and discretion.

### How do I update the executors?

XCutors loader will check for updates to its supported executor list. Follow the prompts within the loader or check the GitHub repository for manual updates.

### My anticomponent flags the files. What should I do?

Some security software may flag executors due to their nature. You can add the folder to your anticomponent exclusions after verifying the source is trusted.

### Can I use my own Lua scripts?

Yes. XCutors and the supported executors allow you to execute any compatible Lua script you have written or obtained.

### Is there a community or support channel?

You can use the GitHub Issues page for bug reports and feature requests. The README may link to community forums for general discussion.
